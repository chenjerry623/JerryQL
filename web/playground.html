How a query runs

      
lexer → parser → AST → planner → operators

      
Hand-written recursive-descent parser. Pull-based (Volcano) operators: scan, filter, sort, limit, project.

    

    

      
What the planner does

      
Conditions on the primary key become a point lookup or a key-range scan instead of reading every row. EXPLAIN shows the plan it chose.

    

    

      
Scope

      
INT and TEXT columns, one INT primary key, no NULLs, joins or aggregates yet. This demo keeps data in memory; reloading the page resets it.
