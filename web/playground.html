JerryQL SQL engine · C++17 → WebAssembly

A SQL database engine written from scratch in C++: parser, query planner, B+tree storage, buffer pool and write-ahead log. Compiled to WebAssembly, it runs entirely in this tab; nothing is sent to a server.

How a query runs

      
lexer → parser → planner → operators → B+tree. A hand-written recursive-descent parser feeds pull-based operators: scan, filter, sort, limit, project.

    

    

      
What's running here

      
The same C++ code as the native build: B+tree pages, a buffer pool and a write-ahead log, here over in-memory files. Reloading the page resets the data.

    

    

      
Scope

      
INT and TEXT columns, one INT primary key, transactions, COUNT/SUM/MIN/MAX/AVG with GROUP BY and HAVING. No NULLs or joins yet. Rows are limited to 1,000 bytes.
